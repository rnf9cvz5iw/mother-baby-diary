# 世界肝炎日丨认识乙型病毒性肝炎，守护肝脏健康

> 更新时间：2026-09-11 (UTC+8)

**认识乙型病毒性肝炎**

**守护肝脏健康**

乙型病毒性肝炎，简称乙肝，是一种由乙型肝炎病毒（HBV）引起的传染性疾病。全球范围内，HBV感染是一个严重的公共卫生问题，据世界卫生组织（WHO）报告，2019年全球HBsAg流行率为3.8%，约有150万新发HBV感染者，2.96亿慢性感染者，82万人死于HBV感染所致的肝衰竭、肝硬化或肝细胞癌等相关疾病。我国乙肝高发，乙型肝炎病毒感染造成的医疗和社会负担很重。我国现有8600万乙肝病毒携带者，有2800万需要治疗，了解乙肝的传播途径、预防措施及治疗原则，对于保护个人和家人的健康具有重要意义。

今天，肝病科带大家一起来认识乙肝，共同守护肝脏健康。

▷

**乙肝是如何传播的？**

乙型肝炎病毒（HBV）是一种DNA病毒，主要存在于感染者的血液、体液和肝脏中。乙肝病毒具有高度的传染性，但通过有效的预防措施可以控制传播。

**乙肝的主要传播途径包括：**

1. 血液传播：使用被乙肝病毒污染的针具、输血及血制品等。

2. 母婴传播：孕妇将病毒传给胎儿或新生儿，多发生在分娩过程中。

3. 性接触传播：与乙肝病毒感染者发生无保护性行为。

4. 日常生活密切接触：家庭成员间共用牙刷、剃须刀等可能导致病毒传播。

在中国，母婴传播是最主要的传播途径，占新发感染的40%～50%。成人主要通过血液和性接触传播。日常工作或生活接触，如同一办公室工作、握手、拥抱、同住一宿舍、同一餐厅用餐和共用厕所等无血液暴露的途径，一般不会传染HBV。

**如何预防乙肝？**

人群对HBV普遍易感。接种乙型肝炎疫苗是预防HBV感染最有效的方法。主要接种对象包括新生儿、婴幼儿、15岁以下未免疫人群和成年高危人群。乙型肝炎疫苗全程需接种3剂，按照0、1、6个月的程序进行接种。除此之外，还应避免使用共用针具、具备安全性行为意识、定期进行体检、乙肝患者家庭全员预防。

**得了乙肝会有什么表现？**

乙肝的临床表现多样，轻重不一，以下是一些常见的症状和体征：

**急性感染：**急性乙型肝炎可能无症状，或有轻微症状，如疲劳、食欲不振、恶心、呕吐、腹痛、尿色深等。部分患者可能出现黄疸，即皮肤和眼睛发黄。

**慢性感染：**慢性乙型肝炎的患者可能长期无症状，或在体检时发现肝功能异常。随着病情进展，可能出现疲劳、右上腹痛、腹胀、恶心等症状。

在严重的情况下，乙肝可能导致肝功能衰竭，表现为极度疲劳、意识模糊、腹水、凝血功能障碍等。需要注意的是，乙肝病毒感染者可能在无症状期，因此定期体检至关重要。

**乙肝如何治疗？**

乙肝的治疗目标是抑制病毒复制，减轻肝脏炎症，防止疾病进展，减少肝硬化和肝癌的风险。常用的治疗方法包括抗病毒治疗、干扰素治疗、联合治疗、肝脏保护治疗等，过去普遍认为乙肝是无法治愈的，要终身携带病毒，如果服用抗乙肝病毒药物，例如恩替卡韦、富马酸丙酚替诺福韦等，也是需要终身服用的。但随着科技的进步和治疗观念的改变，现在乙肝临床治愈的概念已被广泛认可，国家卫生健康委医院管理研究所等单位2023年在全国启动“乙肝临床治愈门诊规范化建设与能力提升项目”，计划到2025年，在全国建设超过百家乙肝临床治愈门诊，实现乙肝诊疗、临床治愈网络广覆盖。

乙肝临床治愈门诊是以“慢性乙型肝炎临床治愈”为目标的专病门诊，为乙肝患者提供以患者为中心的“全病程科学管理”的诊疗新模式，为患者制定个体化的诊疗方案，提供预约挂号、规范检查的一站式服务，项目还将搭建乙肝专病数据库，对患者进行疾病风险预判、智能辅助治疗等。

为更加规范天津地区乙肝诊疗，提高乙肝的诊断率和治疗率，帮助更多乙肝患者实现临床治愈，摘掉乙肝帽子，我院积极响应国家卫健委的号召，开通乙肝临床治愈门诊线上挂号，安排专家坐诊，为更多的慢乙肝患者提供全病程诊疗服务，成为天津首批开通乙肝治愈门诊的医院，并且积极向国家卫健委医管所提交乙肝临床治愈门诊培育基地申请，成为天津首家申请培育基地医院。乙肝临床治愈门诊的开通将为更多的慢乙肝患者带来治愈的希望。

乙肝是一种可防可治的疾病。通过接种乙肝疫苗、避免高危行为、定期体检等措施，可以有效降低乙肝的发病率。关注乙肝，关爱肝脏健康，从现在做起。让我们一起努力，消除乙肝，共创美好未来！
